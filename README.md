# Proyecto grupal CA0204: Cine en datos

Análisis de las 1000 películas mejor calificadas en IMDb para identificar qué características se relacionan con el éxito en taquilla, la valoración del público y la de la crítica especializada.

## Estructura

| Carpeta | Contenido |
|---|---|
| `cod/` | Documento Quarto con el código del análisis |
| `data/` | Datos de entrada |
| `info/` | Enunciados y documentación |
| `config/` | Parámetros del proyecto |
| `res/` | Reportes generados |

## Cómo ejecutar

1. Abrir `Proyecto-Grupal-CA0204.Rproj` en RStudio.
2. Instalar los paquetes `readr`, `magrittr`, `dplyr` y `knitr`.
3. Renderizar `cod/Proyecto_HerramientasDatosI_2026.qmd` con Quarto.
4. Mover el PDF generado a `res/`.
